# Embedded font asset

`NotoSansKR-Regular.otf` is the Korean subset regular face from Noto Sans CJK
version 2.004 (`Sans2.004`). It is embedded in the `cetz-render` binary so
documents can select `Noto Sans KR` without system font discovery or a
`--font-path` argument.
